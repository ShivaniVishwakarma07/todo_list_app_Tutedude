# Todo List API

A REST API for a Todo List application built with Node.js, Express.js, and MongoDB.

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- Postman

## Features

- Create Todo
- Get all Todos
- Get Todo by ID
- Update Todo
- Update Todo status
- Delete Todo
- Search Todos
- Input validation
- Error handling

## Setup

Clone the repository and open the backend folder.

```bash
cd Todo_List_App/backend
npm install
```
